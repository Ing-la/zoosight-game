# ⚙️ API 配置说明

本指南将详细介绍如何配置和使用大模型 API 来生成性格分析报告。

## 🤖 支持的 AI 模型

ZooSight Game 支持以下三种大模型：

1. **Google Gemini** - Google 的大语言模型（推荐）
2. **智谱 AI (GLM)** - 国产大语言模型
3. **通义千问 (Qwen)** - 阿里云的大语言模型

## 🔑 获取 API Key

### Google Gemini

1. 访问 [Google AI Studio](https://ai.google.dev/)
2. 登录您的 Google 账号
3. 点击 "Get API Key"
4. 创建新的 API Key 或使用现有的
5. 复制 API Key

**注意**: Gemini API 目前免费使用，但有限制。

### 智谱 AI (GLM)

1. 访问 [智谱 AI 开放平台](https://open.bigmodel.cn/)
2. 注册/登录账号
3. 进入控制台
4. 创建 API Key
5. 复制 API Key

**注意**: 需要实名认证，有免费额度。

### 通义千问 (Qwen)

1. 访问 [阿里云 DashScope](https://dashscope.aliyun.com/)
2. 注册/登录阿里云账号
3. 进入控制台
4. 创建 API Key
5. 复制 API Key

**注意**: 需要实名认证，有免费额度。

## ⚙️ 配置 API Key

### 方法 1: 在应用内配置（推荐）

1. 启动应用
2. 点击"家长登录"
3. 登录家长账号
4. 在家长面板中，点击"⚙️ API 配置"按钮
5. 选择要使用的大模型
6. 输入对应的 API Key
7. 点击"保存"

**注意**: API Key 会保存在本地（localStorage），不会上传到服务器。

### 方法 2: 使用环境变量（开发环境）

如果需要通过环境变量配置（仅开发环境）：

1. 在项目根目录创建 `.env` 文件
2. 添加以下内容：

```env
# Google Gemini API Key（可选）
VITE_GEMINI_API_KEY=your_api_key_here
```

3. 重启开发服务器

**注意**: 
- 环境变量仅支持 Gemini
- 环境变量优先级低于应用内配置
- `.env` 文件已加入 `.gitignore`，不会被提交到 Git

## 📊 使用说明

### 生成报告

1. **配置 API Key**（如果还没有配置）
   - 在家长面板中配置 API Key

2. **选择用户**
   - 在家长面板中选择要分析的儿童账号

3. **生成报告**
   - 点击"生成报告"按钮
   - 系统会显示"正在调用 [模型名] 分析..."
   - 等待报告生成完成

### 模型状态显示

- **有 API Key**: 显示"正在调用 [模型名] 分析..."
  - Google Gemini → "正在调用 Google Gemini 分析..."
  - 智谱 AI → "正在调用 智谱 AI (GLM) 分析..."
  - 通义千问 → "正在调用 通义千问 (Qwen) 分析..."

- **无 API Key**: 显示"正在使用模拟数据生成报告..."
  - 使用本地模拟数据生成报告
  - 报告质量较低，仅供参考

- **API 调用失败**: 显示"模拟数据（API调用失败）"
  - 自动降级到模拟数据
  - 检查 API Key 和网络连接

### 报告内容

生成的报告包含：

1. **性格分析**
   - 基于用户选择的详细性格分析
   - 优势分析
   - 发展建议

2. **MBTI 类型**
   - 基于性格特征推断的 MBTI 类型
   - 如：ENFP、ISFJ 等

3. **职业建议**
   - 结合性格特点和当前经济背景
   - 适合的职业方向
   - 职业发展建议

## 🔒 隐私和安全

### 数据隐私

- ✅ API Key 存储在本地（localStorage）
- ✅ 不会上传到任何服务器
- ✅ 仅用于调用 AI 服务生成报告
- ✅ 用户数据不会发送给第三方（除了 AI 服务）

### 安全建议

1. **保护 API Key**
   - 不要将 API Key 分享给他人
   - 不要在公共场合显示 API Key
   - 定期更换 API Key（如果可能）

2. **数据备份**
   - 定期备份用户数据
   - API Key 配置也会保存在本地

3. **API 使用限制**
   - 注意各平台的 API 使用限制
   - 避免频繁调用导致超出限制

## 🐛 问题排查

### API Key 无效

**症状**: 报告生成失败，显示"API调用失败"

**解决方法**:
1. 检查 API Key 是否正确
2. 检查 API Key 是否过期
3. 检查网络连接
4. 尝试重新配置 API Key

### 网络错误

**症状**: 报告生成失败，显示网络错误

**解决方法**:
1. 检查网络连接
2. 检查防火墙设置
3. 检查代理设置（如果有）
4. 尝试切换网络

### API 调用超时

**症状**: 报告生成时间过长

**解决方法**:
1. 检查网络连接速度
2. 等待一段时间后重试
3. 如果持续超时，考虑使用其他模型

### 报告质量不佳

**症状**: 生成的报告内容不准确或不相关

**解决方法**:
1. 确保用户完成了足够的游戏场景
2. 尝试使用不同的模型
3. 检查用户选择数据是否完整

## 💡 最佳实践

1. **选择合适的模型**
   - Gemini: 免费，质量较高，推荐使用
   - 智谱 AI: 国产，中文理解好
   - 通义千问: 阿里云，稳定可靠

2. **合理使用 API**
   - 不要频繁调用 API
   - 批量生成报告时注意限制
   - 使用模拟数据测试功能

3. **数据准备**
   - 确保用户完成了多个场景
   - 确保有足够的选择数据
   - 数据越多，分析越准确
