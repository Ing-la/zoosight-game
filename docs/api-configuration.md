## 🤖 支持的 AI 模型

ZooSight Game 支持三种 AI 模型用于生成性格分析报告：

### 1. Google Gemini（推荐）

- **模型名称**：Google Gemini Pro
- **特点**：强大的自然语言处理能力，支持中文
- **适用场景**：生成详细的性格分析报告
- **免费额度**：有免费额度，适合个人使用

### 2. 智谱 AI（Zhipu）

- **模型名称**：GLM-4
- **特点**：国产 AI 模型，中文理解能力强
- **适用场景**：中文场景下的性格分析
- **免费额度**：有免费额度

### 3. 通义千问（Tongyi Qianwen）

- **模型名称**：Qwen
- **特点**：阿里云 AI 模型，中文支持好
- **适用场景**：中文场景下的性格分析
- **免费额度**：有免费额度

## 🔧 配置方法

### 方法 1：在应用内配置（推荐）

1. **启动应用**
2. **登录家长账号**
3. **进入家长面板**
4. **点击"API 配置"按钮**
5. **选择 AI 模型**（Gemini / 智谱 / 通义）
6. **输入 API Key**
7. **点击"保存"**

### 方法 2：通过环境变量配置（开发用）

创建 `.env` 文件（在项目根目录）：

```env
# Google Gemini API Key
VITE_GEMINI_API_KEY=your_gemini_api_key_here

# 智谱 AI API Key
VITE_ZHIPU_API_KEY=your_zhipu_api_key_here

# 通义千问 API Key
VITE_TONGYI_API_KEY=your_tongyi_api_key_here
```

**注意**：环境变量配置主要用于开发环境，生产环境建议使用应用内配置。

## 🔑 获取 API Key

### Google Gemini

1. **访问** [Google AI Studio](https://makersuite.google.com/app/apikey)
2. **登录** Google 账号
3. **创建 API Key**
4. **复制 API Key**

**免费额度**：
- 每分钟 60 次请求
- 每天 1500 次请求

### 智谱 AI

1. **访问** [智谱 AI 开放平台](https://open.bigmodel.cn/)
2. **注册/登录** 账号
3. **创建 API Key**
4. **复制 API Key**

**免费额度**：
- 注册后有一定免费额度
- 具体额度请查看官网

### 通义千问

1. **访问** [阿里云通义千问](https://dashscope.aliyun.com/)
2. **注册/登录** 阿里云账号
3. **开通服务**
4. **创建 API Key**
5. **复制 API Key**

**免费额度**：
- 新用户有免费额度
- 具体额度请查看官网

## 📖 使用说明

### 配置 API Key

1. **打开应用**
2. **登录家长账号**
3. **进入家长面板**
4. **点击"API 配置"**
5. **选择模型并输入 API Key**
6. **保存配置**

### 生成报告

1. **在家长面板中选择要分析的儿童账号**
2. **点击"生成报告"**
3. **系统会调用配置的 AI 模型生成报告**
4. **报告生成后会自动显示**

### 切换模型

1. **进入 API 配置**
2. **选择不同的模型**
3. **输入对应的 API Key**
4. **保存配置**

### 使用模拟数据

如果没有配置 API Key 或 API 调用失败，系统会自动使用**模拟数据**生成报告。

模拟数据的特点：
- ✅ 无需 API Key
- ✅ 无需网络连接
- ✅ 快速生成
- ⚠️ 报告内容是预设的，不是真实的 AI 分析

## 🔒 数据安全

### API Key 存储

- **存储位置**：本地 `localStorage`
- **安全性**：不会上传到任何服务器
- **隐私保护**：只有本地应用可以访问

### 数据使用

- **仅用于生成报告**：API Key 仅用于调用 AI 服务生成性格分析报告
- **不上传用户数据**：用户的游戏选择数据不会上传到 AI 服务
- **本地处理**：所有数据处理都在本地完成

## 🐛 常见问题

### Q: API Key 配置后无法生成报告？

**A:** 检查以下几点：

1. **API Key 是否正确**：确保复制了完整的 API Key，没有多余空格
2. **网络连接**：确保网络连接正常
3. **API 额度**：检查 API Key 是否还有可用额度
4. **模型选择**：确保选择的模型与 API Key 匹配

### Q: 报告生成失败怎么办？

**A:** 系统会自动使用模拟数据生成报告。如果希望使用真实 AI 分析：

1. 检查 API Key 配置
2. 检查网络连接
3. 查看控制台错误信息
4. 尝试切换其他 AI 模型

### Q: 可以同时配置多个 API Key 吗？

**A:** 不可以。一次只能配置一个 AI 模型。如果需要切换，可以在 API 配置中更改。

### Q: API Key 会过期吗？

**A:** 取决于各个 AI 服务商的政策：

- **Google Gemini**：API Key 不会过期，但免费额度有限制
- **智谱 AI**：API Key 不会过期，但需要定期使用
- **通义千问**：API Key 不会过期，但需要定期使用

建议定期检查 API Key 是否还有可用额度。

### Q: 如何查看 API 使用情况？

**A:** 可以在各个 AI 服务商的官网查看：

- **Google Gemini**：[Google AI Studio](https://makersuite.google.com/app/apikey)
- **智谱 AI**：[智谱 AI 开放平台](https://open.bigmodel.cn/)
- **通义千问**：[阿里云控制台](https://dashscope.aliyun.com/)

### Q: 免费额度用完了怎么办？

**A:** 可以：

1. **等待额度重置**：大多数服务商会定期重置免费额度
2. **购买付费额度**：在服务商官网购买
3. **使用模拟数据**：系统会自动使用模拟数据生成报告

## 💡 最佳实践

### 1. 选择合适的模型

- **中文场景**：推荐使用智谱 AI 或通义千问
- **英文场景**：推荐使用 Google Gemini
- **免费使用**：优先使用有免费额度的模型

### 2. 保护 API Key

- **不要分享**：不要将 API Key 分享给他人
- **不要提交到 Git**：确保 `.env` 文件在 `.gitignore` 中
- **定期更换**：如果怀疑泄露，及时更换 API Key

### 3. 监控使用情况

- **定期检查**：定期检查 API 使用情况
- **设置提醒**：在服务商设置使用量提醒
- **合理使用**：避免过度使用导致额度耗尽
