## 🦁 关于 ZooSight Game

ZooSight Game 是一个以**疯狂动物城**为背景的儿童教育游戏。在这个动物世界里，孩子们会遇到：

- 🦒 **长颈鹿老师** - 温柔耐心的学校老师
- 🐘 **大象保安** - 负责学校安全的保安
- 🦊 **狐狸同学** - 活泼友好的同学
- 更多有趣的动物角色...

通过在不同场景中的选择，系统会分析孩子的性格特征，并生成个性化的 MBTI 性格报告。
