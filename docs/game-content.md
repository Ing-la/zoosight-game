# 🎮 游戏内容介绍

## 📍 游戏场景

### 🏫 学校场景

#### 🚪 进校门事件
- **描述**: 早上来到学校门口，遇到长颈鹿老师和同学们
- **角色**: 
  - 长颈鹿老师 - 温和友善的老师
  - 狐狸同学 - 活泼的同学
  - 大象保安 - 负责安全的保安
- **互动内容**: 
  - 与老师打招呼
  - 与同学互动
  - 配合保安测体温
  - 选择进入学校的方式

#### 🍽️ 午餐时间事件
- **描述**: 在学校食堂吃午餐时的互动
- **互动内容**: 
  - 选择座位
  - 与同学交流
  - 处理午餐问题

### 🎠 游乐场场景

#### 🛝 滑滑梯事件
- **描述**: 在游乐场玩滑滑梯时的互动
- **互动内容**: 
  - 选择玩滑滑梯的方式
  - 与小伙伴互动
  - 处理排队问题

#### 🎢 荡秋千事件
- **描述**: 在游乐场荡秋千时的互动
- **互动内容**: 
  - 选择荡秋千的方式
  - 与小伙伴分享
  - 处理等待问题

## 👥 游戏角色

### 长颈鹿老师 🦒
- **性格**: 温和、友善、耐心
- **特点**: 总是关心学生，用温和的方式引导
- **出现场景**: 学校场景

### 狐狸同学 🦊
- **性格**: 活泼、外向、友好
- **特点**: 喜欢交朋友，总是充满活力
- **出现场景**: 学校场景、游乐场场景

### 大象保安 🐘
- **性格**: 认真、负责、温和
- **特点**: 负责学校安全，但很友善
- **出现场景**: 学校场景

## 🎯 游戏机制

### 选择系统

每个场景包含多个互动节点，每个节点提供多个选择：

- **对话选择** - 选择如何回应角色
- **行为选择** - 选择如何行动
- **情绪选择** - 选择情绪表达方式

### 性格特征评分

每个选择都会影响性格特征的得分：

- **外向** - 选择主动交流、大声说话等
- **内向** - 选择安静、害羞等
- **独立** - 选择自己解决问题
- **依赖** - 选择寻求帮助
- **规则意识** - 选择遵守规则
- **社交** - 选择与他人互动
- **沟通** - 选择表达自己的想法
- **礼貌** - 选择礼貌的行为
- **友善** - 选择友好的行为
- **创新** - 选择创新的方式
- **耐心** - 选择等待、耐心处理

### 数据收集

系统会记录：
- 所有选择的内容
- 每个性格特征的得分
- 完成的场景数量
- 游戏时间

## 📊 分析报告

### 性格分析

基于用户的所有选择数据，AI 会生成：
- 性格特点分析
- 优势分析
- 发展建议

### MBTI 类型

根据性格特征得分，推断 MBTI 类型：
- **E/I** - 外向/内向
- **S/N** - 感觉/直觉
- **T/F** - 思考/情感
- **J/P** - 判断/知觉

### 职业建议

结合性格特点和当前经济背景，提供：
- 适合的职业方向
- 职业发展建议
- 能力培养建议

## 🎨 视觉设计

### 色彩方案

- **主色调**: 紫色渐变（#667eea → #764ba2）
- **背景**: 渐变背景，营造温馨氛围
- **卡片**: 白色卡片，圆角设计

### 图标系统

- 使用 Emoji 作为场景图标
- 简洁明了的视觉标识
- 符合儿童审美

## 🔄 游戏流程

1. **登录/注册** - 创建或登录账号
2. **选择场景** - 选择想要探索的地点
3. **选择事件** - 选择具体的事件
4. **进行互动** - 根据提示做出选择
5. **完成场景** - 完成所有互动节点
6. **查看报告** - 在家长面板查看分析报告

## 💡 设计理念

### 儿童友好

- 简洁的界面设计
- 清晰的文字说明
- 友好的角色形象
- 积极的引导方式

### 教育意义

- 培养社交能力
- 培养规则意识
- 培养独立能力
- 培养表达能力

### 隐私保护

- 所有数据本地存储
- 不上传任何数据
- 家长可随时查看
- 可随时删除数据
