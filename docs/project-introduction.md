# 🎮 ZooSight Game - 项目介绍

## 📋 项目概述

ZooSight Game 是一个基于 Electron + React 开发的桌面端儿童情景游戏应用。通过情景互动的方式，帮助分析儿童的性格特征，并提供专业的 MBTI 性格分析和职业发展建议。

## ✨ 核心功能

- **🎮 情景互动游戏** - 通过选择探索不同场景（学校、游乐场等）
- **👥 多用户系统** - 支持儿童账号和家长账号分离管理
- **📊 性格分析报告** - 基于用户选择数据生成详细的性格分析报告
- **🧠 MBTI 性格类型分析** - 专业的 MBTI 性格类型推断
- **💼 职业发展建议** - 结合当前经济背景的职业建议
- **🎨 儿童友好的 UI 设计** - 简洁美观的界面设计
- **🔒 数据隐私保护** - 所有数据存储在本地，不上传服务器
- **🤖 多 AI 模型支持** - 支持 Google Gemini、智谱 AI、通义千问

## 🏗️ 技术架构

### 前端技术栈

- **Electron** - 跨平台桌面应用框架
- **React 18** - 现代化的 UI 框架
- **Vite** - 快速的构建工具
- **React Router** - 客户端路由管理
- **Zustand** - 轻量级状态管理

### AI 集成

- **Google Gemini API** - Google 的大语言模型
- **智谱 AI (GLM)** - 国产大语言模型
- **通义千问 (Qwen)** - 阿里云的大语言模型

### 数据存储

- **localStorage** - 本地数据存储（用户数据、游戏记录、API 配置）

## 🎯 设计理念

### 模块化场景架构

项目采用**模块化场景架构**，每个场景（地点）都有独立的目录，包含：
- **场景配置** (`config.json`) - 定义场景的对话、选项等
- **资源文件** (`assets/`) - 场景的图片、音效等资源

这种设计的优势：
- ✅ **模块化** - 每个场景独立，互不干扰
- ✅ **易扩展** - 添加新场景只需创建目录和配置文件
- ✅ **资源集中** - 场景资源集中管理，完全封装在场景目录下
- ✅ **维护性** - 修改场景不影响其他场景

### 数据隐私保护

- 所有用户数据存储在本地（使用 localStorage）
- 不会上传任何数据到服务器
- API Key 仅用于调用 AI 服务生成报告
- 建议定期备份用户数据

## 🔄 工作流程

1. **儿童用户** 注册/登录账号
2. **选择场景** 和事件（如：学校-进校门）
3. **进行互动** 根据情景提示做出选择
4. **完成场景** 系统记录选择数据
5. **家长查看** 在家长面板中查看分析报告
6. **AI 分析** 使用配置的大模型生成性格分析报告

## 📊 性格特征系统

游戏通过记录用户的选择来分析以下性格特征：

- **外向/内向** - 社交倾向
- **独立/依赖** - 自主能力
- **规则意识** - 遵守规则的程度
- **社交能力** - 人际交往能力
- **沟通能力** - 表达能力
- **礼貌** - 礼貌程度
- **友善** - 友好程度
- **创新** - 创新思维
- **耐心** - 耐心程度
