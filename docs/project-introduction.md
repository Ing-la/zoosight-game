# 📖 项目介绍

## 🎮 ZooSight Game

**ZooSight Game** 是一个基于 Electron + React 开发的桌面端儿童情景游戏，以**疯狂动物城（Zootopia）**为设计灵感，通过动物角色的互动场景，帮助分析儿童性格特征。

### 🌟 项目特色

- 🦁 **疯狂动物城主题** - 以 Zootopia 为背景，充满趣味性的动物角色设计
- 🎮 **情景互动游戏** - 通过选择探索不同场景（学校、游乐场等）
- 👥 **多用户系统** - 支持儿童账号和家长账号分离
- 📊 **性格分析报告** - 基于用户选择数据生成详细的性格分析报告
- 🧠 **MBTI 性格类型分析** - 专业的 MBTI 性格类型推断
- 💼 **职业发展建议** - 结合当前经济背景的职业建议
- 🎨 **儿童友好的 UI 设计** - 简洁美观的界面设计
- 🔒 **数据隐私保护** - 所有数据存储在本地，不上传服务器
- 🤖 **多 AI 模型支持** - 支持 Google Gemini、智谱 AI、通义千问

## 🏗️ 技术架构

### 核心技术栈

- **Electron** - 跨平台桌面应用框架
- **React 18** - 现代化 UI 框架
- **Vite** - 快速构建工具
- **React Router** - 单页应用路由管理
- **Zustand** - 轻量级状态管理
- **Google Gemini API** / **智谱 AI** / **通义千问** - AI 分析引擎

## 🎨 设计理念

### 疯狂动物城（Zootopia）主题

本项目以迪士尼动画电影《疯狂动物城》为设计灵感，创造了一个充满动物角色的虚拟世界：

- **动物角色设计**：每个角色都是不同的动物，具有独特的性格特征
  - 🦒 长颈鹿老师 - 温柔、耐心、负责
  - 🐘 大象保安 - 严肃、负责、保护
  - 🦊 狐狸同学 - 活泼、友好、聪明

- **场景设计**：场景设计充满童趣，符合儿童认知
  - 🏫 学校场景 - 日常学习生活
  - 🎠 游乐场场景 - 娱乐和社交

- **互动设计**：通过选择不同的行为选项，反映孩子的性格特征

### 教育价值

- **性格认知**：帮助孩子了解自己的性格特点
- **社交能力**：通过情景模拟，培养社交技能
- **决策能力**：通过选择，培养决策思维
- **自我表达**：鼓励孩子表达自己的想法

## 🚀 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 7.0.0

### 安装和运行

```bash
# 克隆项目
git clone https://github.com/Ing-la/zoosight-game.git
cd zoosight-game

# 安装依赖
npm install

# 开发运行
npm run dev

# 构建应用
npm run build

# 打包 Electron 应用
npm run build:electron
```

详细说明请参考 [开发指南](./development-guide.md)。
